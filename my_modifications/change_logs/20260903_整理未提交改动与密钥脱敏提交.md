## 🔧 具体改动

### 1. `.gitignore`：补充忽略规则

```gitignore
# 含真实 API Key 的私有环境配置，禁止入库（本机/服务器各自维护）
.env.server
.env.windows

# 本地实验产物与向量库
db/
llm_controller/excel/
llm_controller/result/
llm_controller/video/*.mp4
```

说明：
- 代码与日志入库；真实 `.env.windows` / `.env.server` 保留在各自机器磁盘上（Git 不会删除已存在的未跟踪文件，服务器 `git pull` 后配置仍在）。
- 新环境首次配置请复制 `.env.example` 后填写真实 Key，`.env.example` 本身可入库（只含占位符/注释）。
- `db/`、`llm_controller/result/`、`excel/`、临时 `video/*.mp4` 为运行产物，不入库。

### 2. `run_server.sh`：去除密钥回显 + 缺失检查

原脚本 `cat .env` 会把完整配置（含 API Key）打印到终端。改为：

```bash
if [ ! -f .env.server ]; then
    echo "错误：未找到 .env.server ..." >&2
    exit 1
fi
cp .env.server .env
grep '^LLM_MODEL' .env || true   # 只显示模型名，不回显 Key
```

### 3. `run_windows.bat` / `run_experiment.bat`：缺失配置时报错退出

两个脚本在 `copy .env.windows` 前增加存在性检查：找不到 `.env.windows` 时明确提示从 `.env.example` 创建并退出，避免误用默认值（如 Windows 上误拉取 qwen2.5:32b）或静默失败。
