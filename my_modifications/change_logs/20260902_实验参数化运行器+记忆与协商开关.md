## 🎯 修改目的

个人电脑改用 **8B 本地模型**（Ollama qwen3:8b）后，需要批量跑实验（0shot/2shot/5shot/no-negotiation 多方法多场景）。原代码把场景、方法、轮次全部**写死**在 `Run_multi_CAV_LLM.py` 顶部：
- `env = gym.make('intersection-multi-agent-v0')` 固定场景
- `for i in range(2)` 固定 2 轮
- 记忆检索、协商调用在主循环里**无条件执行**，无法单独关闭

因此做三处改造：**命令行参数化、记忆开关（few-shot）、协商开关（no-negotiation）**，并让每轮自动记录 `progress.json` 指标，支撑后续统计。

## 🔧 具体改动

### 改动 1：[Run_multi_CAV_LLM.py](Run_multi_CAV_LLM.py) 整体参数化重写

**原代码（写死）：**
```python
env = gym.make('intersection-multi-agent-v0')
for i in range(2):
    # ... 每轮每步都无条件调用协商 + 决策 LLM
```

**改成：argparse 接收 `--scene / --method / --n / --start / --output_dir`**

```python
parser.add_argument("--scene", choices=["intersection", "merge", "highway"])
parser.add_argument("--method", choices=["0shot", "2shot", "5shot", "no-negotiation"])
parser.add_argument("--n", type=int, default=10)      # 本轮总轮次
parser.add_argument("--start", type=int, default=0)   # 起始轮次（断点续跑）
parser.add_argument("--output_dir")                   # 输出根目录

use_memory = args.method in ("2shot", "5shot")
memory_top_k = 2 if args.method == "2shot" else 5
use_negotiation = args.method != "no-negotiation"
```

**输出目录按 `结果根/<scene>/<method>/{data, video, progress.json, db}` 隔离。**

**每轮写 `progress.json`（断点续跑时 `--start` 跳过已完成轮）：**
```json
{
  "round": 0, "scene": "intersection", "method": "0shot",
  "success": true, "num_cav": 4, "num_crashed": 0, "num_arrived": 4,
  "timeout": false, "avg_speed": 5.2, "total_steps": 45,
  "llm_calls": 8, "parse_failures": 0, "duration_seconds": 180
}
```

**成功判定（写入 `success` 字段）：**
- intersection / merge：`num_crashed == 0` 且 `num_arrived >= 1`
- highway：`num_crashed == 0`（跑完即成功，该环境无 `has_arrived`）

### 改动 3：[memory.py](llm_controller/memory.py) 记忆库按场景/方法隔离

**原代码：**
```python
db_path = './db/' + str(env.spec.id)
```

**改成：支持 `MEMORY_DB_DIR` 环境变量，注入时用 `<MEMORY_DB_DIR>/<env_id>` 建库**
```python
db_base = os.getenv("MEMORY_DB_DIR") or './db/'
db_path = os.path.join(db_base, str(env.spec.id))
os.makedirs(db_base, exist_ok=True)
```
未注入时保持原行为 `./db/<env_id>`。这样每个方法（0shot/2shot/5shot）的记忆库互相隔离，0shot 检索不到其他方法的旧数据。
